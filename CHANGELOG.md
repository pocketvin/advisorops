# Changelog

## 0.6.0 — GitHub-ready / batch customer administration

- Finalized product name: AdvisorOps.
- Added CSV import preview, field normalization and template/sample downloads.
- Added batch selection and guarded bulk customer deletion.
- Added Import Guide, Evolution document, contribution guide and GitHub templates.
- Removed implicit dependency on a sibling local project for AI configuration.
- Unified frontend/backend package metadata to 0.6.0.
- Added explainable customer operating judgment cards with traceable evidence and explicit hypothesis labeling.

## 0.5.x — richer client context and lower-friction progress capture

- Added global quick-record flow.
- Added multidimensional customer profile and hypothesis separation.
- Added image attachment understanding and Activity attachment persistence.
- Replaced fixed “3 days later” with flexible follow-up scheduling.
- Expanded customer detail workspace.

## 0.4.x — complete client-operations loop

- Added Work Area / Discovery Area separation.
- Added Current Snapshot, Activity, WorkItem, Field Change Audit and Change Proposal.
- Added mock multi-source Activity Inbox with cursor/idempotency semantics.
- Added deterministic Priority and time-based discovery return.
