# 面试 Demo 场景

## 主线

1. 打开“今日工作台”，说明这里是今天的工作队列，不是客户价值榜。
2. 点第一名“为什么排在这里”，展示每一项加减分。
3. 打开客户详情，展示时间线、最近反馈和下一步工作建议。
4. 记录一次“明确拒绝”，保存后回到工作台：客户立即后移。
5. 找到一个已到约定跟进日的“考虑中”客户：无需人工操作，他已经自动回到重点列表。

## 五个验收场景

### 1. 重点沟通 + 置顶
置顶后解释项出现“客户经理人工置顶 +100”，客户进入前列。

### 2. 明确拒绝
记录“暂时没有需求”后：
- stage 变为 rejected
- 清除人工置顶
- 默认进入 30 天冷静期
- 优先级显著下降
- 下一步变为避免短期反复打扰

### 3. 再考虑
选择“再考虑 3 天”后，当天下降；到期后由时间规则自动回流。

### 4. 新增行为信号
给普通客户增加近期资产变化或新的关注主题后，分数和解释即时变化。建议先核实需求变化，不直接形成产品结论。

### 5. 完成跟进
记录本次动作、反馈、阶段、意向、下一步和下次联系时间。保存后时间线增加事件，工作台重新排序。
