# 产品模型

## 客户阶段与今日优先级

客户阶段描述关系进展：
- new：尚未形成有效沟通
- contacted：已联系但暂无明显意向
- interested：已表达需求或兴趣
- considering：客户需要时间考虑，并存在约定回访时间
- rejected：近期明确拒绝
- dormant：较长时间无有效互动

follow_up_due 是派生工作状态：当 next_contact_at 已到期且客户不处于 rejected 时，根据当前时间自动显示，不依赖后台定时任务。

今日优先级只回答“今天先花时间在谁身上”，不是成交概率，也不是客户价值评级。

## V1 规则

每个加减分项都输出中文解释：
- 意向：high +25 / medium +15 / low +5
- 跟进：逾期 +25；今日到期 +20；24 小时内 +10；明显未到期 -10
- 阶段：interested +15；considering +8；contacted +5；new +8；dormant -8；rejected -45
- 行为：资产变化、近期登录或交易、最近关注主题分别小幅加分
- 客户价值：仅轻权重辅助
- 人工置顶：+100
- 打扰保护：近期刚联系且没有到期约定时降权

优先级标签：
- >= 70：高
- >= 40：中
- < 40：低

## Next Best Action

NBA 给出的是客户经理下一步工作动作，例如按约定回访、继续需求澄清、先核实近期行为变化、进入冷静期或重新做服务回访。涉及具体产品时必须先核验适当性并由客户经理确认。

## 到期回流

“再考虑 3 天”只保存 next_contact_at。加载工作台时实时比较当前时间：
- 未到期：客户暂时后移
- 到期：获得跟进到期加分并显示 follow_up_due
- 逾期：继续保留较高工作优先级

## 边界

所有数据均为模拟数据；不暗示接入任何券商内部系统；不自动发送客户沟通内容；不自动替客户经理做投资决策。
